Application Surface

Dashboards & Data

The frontend includes market overview, equity, heatmap, and backtest panels backed by FastAPI routes and persisted run data.

Dashboard tabs

Market

Index snapshots, market news, USD/INR, and broad market context from public data sources.

Equity

Symbol-level views, quote data, price charts, and technical context.

Backtests

Persisted runs with metrics, equity curves, benchmark comparison, trades, and cost breakdowns.

Heatmap

NSE index and sector heatmap views built from public market endpoints.

Strategy page

Multi-Asset Strategy Runs

The strategy surface supports equities, commodities, Indian indices, global indices, ETF/mutual-fund proxies, and crypto pairs where the configured data sources provide usable history. Runs are deterministic and can be reviewed later in dashboards.
