Guide

Quickstart

Run the local market-analysis app with Python 3.12+, uv, Node.js, and npm. The AI chat key is optional unless you use `/chat`.

Step 01

Clone & Install

The backend is managed with uv.

git clone https://github.com/dharunashokkumar/indie-market-analyst.git
cd indie-market-analyst
uv sync
cp .env.example .env

Add OPENROUTER_API_KEY only if you plan to use the AI-assisted chat.

Step 02

Run the Backend

Start the FastAPI gateway for intraday, dashboards, strategy, sessions, runs, market data, and chat.

uv run uvicorn indie_market_analyst.api_server:app --reload
Step 03

Launch the Interface

The frontend is a React app powered by Vite.

cd frontend
npm install
npm run dev

Open http://localhost:5173. Start with /intraday, /dashboards, /strategy, or /chat.

Common paths

Intraday

Open /intraday, choose a universe and source, then run a scan. Use /intraday/settings for NSE cookies and source defaults.

Strategy & Backtests

Open /strategy to run deterministic strategies. Review persisted results in /dashboards?tab=backtests.

CLI

Optional Chat Utilities

The CLI is mainly useful for the AI chat feature and tool inspection.

uv run indie-analyst chat
uv run indie-analyst tools
uv run indie-analyst teams
Docs

Preview the Static Docs Locally

Serve the docs/ directory locally before publishing.

python3 -m http.server 4173 -d docs

Then open http://localhost:4173.
