Backtester

A deterministic pandas/numpy engine for strategy runs, trade logs, metrics, and Indian transaction costs. It can be used directly, through APIs, or through dashboard panels.

01

The Indian Cost Model

Many backtests assume zero friction or a flat percentage. This engine models the actual Indian cash-equity cost stack:

  • · STT
  • · Stamp duty
  • · Exchange transaction charges
  • · SEBI turnover fees
  • · GST on brokerage and charges
  • · Zerodha-style brokerage cap
02

Strategies & Metrics

Strategy modules emit deterministic signal series. The runner derives trades, applies costs, stores run blobs, and returns metrics for the UI.

  • Sharpe, Sortino, Calmar, and annualized volatility
  • Maximum drawdown and equity curve
  • Win rate, expectancy, trade log, and cost breakdown
  • Benchmark comparison where data coverage is sufficient
Usage

Running a Simulation

Use the `/strategy` page, dashboard backtest tab, backend API, or Python modules directly.

from backtest import runner

result = runner.run(
    symbol="RELIANCE.NS",
    strategy="momentum",
    period="1y",
    initial_capital=100000,
)

print(result["metrics"]["sharpe"])
