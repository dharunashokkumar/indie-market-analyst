Optional AI Feature

AI Chat & Tools

The chat feature uses YAML-defined agent teams, source-backed tools, strict schemas, and guardrails. It is useful for explanations and reports, but deterministic scanner and backtest paths do not depend on it.

Config

Teams as YAML

Teams live in config/swarm/*.yaml. They declare agents, roles, tools, skills, handoffs, and output types.

name: equity_research
agents:
  - name: collector
    role: collector
    tools: [get_quote, get_history]
    output_type: CollectorOutput
  - name: verifier
    role: verifier
    handoffs: [calculator]
    output_type: VerifiedFacts
  - name: calculator
    role: calculator
    output_type: CalculationBundle
Registry

Tool Discovery

Drop a Python module under indie_market_analyst/tools/ and export TOOLS. The registry discovers it for chat teams.

from agents import function_tool
from pydantic import BaseModel, ConfigDict

class QuoteResult(BaseModel):
    model_config = ConfigDict(extra="forbid")
    symbol: str
    last_price: float
    source: str
    as_of: str

@function_tool
def get_custom_quote(symbol: str) -> QuoteResult:
    ...

TOOLS = [get_custom_quote]
Skills

Prompt Fragments

Skills are small prompt and metadata packages under indie_market_analyst/skills/. They give a chat agent a specialized behavior without hardcoding it into the dispatcher.

Use skills for report writing, narrow research styles, or temporary tool allowlists. Do not put deterministic scanner rules in prompts.

Guardrails

Source-Backed Numbers

Numeric claims should come from tool calls in the current turn and flow through typed models before final prose is produced.
