Manifesto

The open-source AI research analyst for Indian markets.

Free data. Transparent reasoning. Swarm-orchestrated. Built for those who refuse to trust black-box financial models.

Get Started → GitHub
The Problem

Most financial LLMs hallucinate closing prices.

Generic AI agents often prioritize fluency over factual accuracy. In the world of Indian stock markets (NSE/BSE), a hallucinated decimal point isn't just a typo—it's a liability. Indie-market-analyst inverts the default: an agent may only talk about numbers it pulled from a verified tool call on this turn.

The Approach

Tool-First Design

A reflection-based registry allows you to drop a Python module into the tools directory and have it instantly wired for agent use.

Swarm Orchestration

Teams live as YAML; add a team without touching Python. Orchestrate complex research flows across multiple specialized agents.

Strict Handoffs

Every handoff between agents carries a strict Pydantic schema, ensuring no data loss or corruption in the chain.

Philosophy
"We don't need smarter models; we need better guardrails for the models we have."
