Overview

A market-analysis workspace for Indian traders and builders.

Deterministic intraday scans, dashboards, strategy backtests, source-backed data tools, and an optional AI chat in one local-first app.

Get Started → Intraday Scanner GitHub
What it includes

Intraday Scanner

Seven IST-aware modes, NSE direct plus yfinance fallback, configurable universes, price-volume detectors, probability ranking, JSON storage, and chart overlays.

Dashboards & Data

Market overview, equity panels, index heatmaps, instrument search, commodities, indices, ETF proxies, and persisted backtest runs.

Backtester

Pure pandas/numpy strategy runs with Indian transaction costs, trade logs, metrics, and dashboard-ready persistence.

AI-Assisted Chat

Optional OpenRouter-backed chat using YAML teams, source-aware tools, strict Pydantic handoffs, and guardrails for numeric claims.

Core principle

Use deterministic code for market decisions. Use AI only where it helps explain or assemble context.

The scanner, scoring, charts, strategy runs, cost model, and persisted outputs are normal Python and TypeScript paths. The chat feature can call tools and write notes, but it is not the foundation of the product.

Primary workflow
  1. Start the FastAPI backend and Vite frontend.
  2. Use `/intraday` for live scans or `/strategy` for strategy testing.
  3. Review charts, overlays, detector evidence, and persisted runs in the UI.
  4. Use `/chat` when you want an AI-assisted explanation backed by tool calls.
