Intraday Scanner

A Python engine and React UI for NSE intraday workflows. It uses data sources, filters, setup detectors, and scoring code instead of LLM interpretation.

Modes

Pre-Market

Global cues, ADRs, FX, commodities, FII/DII context, and watchlist seed.

Live & Last Hour

Universe scan, detectors, probability ranking, picks table, and chart overlays.

Review & Planning

Post-market review, active-pick updates, single-symbol analysis, and weekend planning.

Scan pipeline 
universe
  -> top movers merge
  -> NSE direct or yfinance candles
  -> liquidity + ASM/GSM tagging
  -> ORB, VWAP, breakout, flag, momentum, short-cover detectors
  -> direction + probability + conviction
  -> JSON scan result
  -> table + lightweight-charts overlays
Controls

The UI exposes the knobs needed during market hours: universe selection, source selection, manual mode override, run button, auto-poll toggle, interval picker, chart overlay toggles, and source settings for NSE cookies.
